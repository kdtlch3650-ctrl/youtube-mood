# KOTE 기반 감정 라벨 활용 기준

이 프로젝트의 AI 모델은 KOTE 감정 라벨을 기준으로 학습한다.

서비스에서 사용하는 음악 분위기 태그는 AI가 직접 학습하지 않고, 백엔드 추천 로직에서 감정 라벨을 바탕으로 생성한다.

## 1. 전체 흐름

```text
사용자 자연어 입력
→ AI 모델이 KOTE 감정 라벨 예측
→ 백엔드가 감정 라벨을 분위기 태그로 변환
→ 분위기 태그로 YouTube 검색 키워드 생성
→ 추천 곡과 플레이리스트 표시
```

이렇게 나누는 이유는 감정 분석과 음악 추천의 역할이 다르기 때문이다.

AI 모델은 사용자의 감정을 잘 맞히는 데 집중한다.
음악 추천 로직은 그 감정에 어울리는 분위기를 만드는 데 집중한다.

## 2. KOTE를 우선 기준으로 쓰는 이유

KOTE는 한국어 온라인 문장에 여러 감정 라벨을 붙인 공개 데이터셋이다.

이 프로젝트에서 KOTE를 우선 사용하는 이유는 아래와 같다.

- 한국어 감정 표현을 다룬다.
- 단순 긍정/부정이 아니라 세부 감정 라벨을 제공한다.
- 한 문장에 여러 감정이 붙을 수 있는 멀티라벨 구조다.
- 직접 만든 소량 데이터보다 학습 안정성이 높다.

## 3. 모델이 예측할 값

모델은 KOTE 감정 라벨만 예측한다.

예시:

```json
{"text":"오늘 너무 지치고 아무것도 하기 싫다","labels":["힘듦/지침","귀찮음"]}
```

모델은 아래 값을 직접 예측하지 않는다.

- 음악 분위기 태그
- YouTube 검색어
- 추천 곡
- 추천 플레이리스트

이 값들은 서비스 로직에서 만든다.

## 4. 감정 라벨과 분위기 태그 분리

감정 라벨은 사용자의 상태를 설명한다.

예시:

- `힘듦/지침`
- `불안/걱정`
- `화남/분노`
- `슬픔`

분위기 태그는 추천할 음악의 방향을 설명한다.

예시:

- `soft`
- `quiet`
- `warm`
- `heavy`
- `uplifting`

같은 감정이라도 사용자가 원하는 음악 방향은 다를 수 있다.

예를 들어 `불안/걱정`이 예측되더라도 항상 어두운 음악을 추천하면 안 된다.
사용자 문장에 “너무 무거운 음악은 싫다”는 표현이 있으면 `soft`, `light` 같은 분위기가 더 적합하다.

## 5. 1차 감정-분위기 매핑 초안

아래 표는 추천 로직에서 사용할 수 있는 1차 매핑 초안이다.

| KOTE 감정 라벨 | 서비스 분위기 태그 |
| --- | --- |
| `힘듦/지침` | `soft`, `quiet`, `warm` |
| `귀찮음` | `light`, `minimal` |
| `불안/걱정` | `soft`, `quiet`, `warm` |
| `슬픔` | `warm`, `soft`, `late night` |
| `서러움` | `warm`, `soft` |
| `절망` | `warm`, `quiet` |
| `화남/분노` | `heavy`, `uplifting` |
| `짜증` | `heavy`, `uplifting` |
| `행복` | `uplifting`, `light` |
| `기쁨` | `uplifting`, `light` |
| `즐거움/신남` | `uplifting`, `light` |
| `기대감` | `uplifting`, `light` |
| `편안/쾌적` | `soft`, `quiet` |
| `안심/신뢰` | `warm`, `soft` |

KOTE 원본에 없는 서비스용 라벨은 모델 학습 라벨로 추가하지 않는다.
필요하면 추천 로직의 매핑에서만 다룬다.

## 6. 데이터 변환 원칙

KOTE 원본 데이터를 사용할 때는 원본 라벨을 최대한 유지한다.

변환이 필요한 경우에도 아래 원칙을 따른다.

- 원본 문장은 임의로 수정하지 않는다.
- 원본 감정 라벨을 서비스용 영어 태그로 바로 덮어쓰지 않는다.
- 모델 학습 데이터와 추천용 매핑 데이터를 분리한다.
- 라벨이 너무 드문 경우는 학습에서 제외하거나 상위 감정으로 묶는 방안을 따로 검토한다.

## 7. 현재 결정

현재 프로젝트에서는 아래 방향을 따른다.

- AI 모델: KOTE 감정 라벨 예측
- 추천 로직: KOTE 감정 라벨을 음악 분위기 태그로 변환
- 검색 로직: 분위기 태그와 사용자 문장을 바탕으로 YouTube 검색어 생성

이 구조를 사용하면 공개 데이터셋의 장점을 살리면서도 음악 추천 서비스의 방향을 유지할 수 있다.
