# AI 학습 데이터 라벨링 기준

이 문서는 사용자의 자연어 문장에 감정 태그와 분위기 태그를 붙일 때 사용하는 기준이다.

목표는 모든 감정을 완벽하게 분류하는 것이 아니라, 음악 추천에 필요한 감정과 분위기를 일관되게 예측할 수 있는 데이터를 만드는 것이다.

## 1. 데이터 형식

학습 데이터는 JSON Lines 형식으로 작성한다.

한 줄은 하나의 학습 예시다.

```json
{"text":"지쳤지만 너무 무거운 음악은 싫고 조금 차분한 분위기가 좋다","emotions":["tired","calm"],"mood_tags":["soft","quiet"]}
```

## 2. 감정 태그 기준

`emotions`는 사용자가 현재 느끼는 감정 상태를 나타낸다.

감정 태그는 문장에 직접 드러난 감정을 우선으로 붙인다.

| 태그 | 의미 | 예시 문장 |
| --- | --- | --- |
| `happy` | 기분 좋음, 즐거움 | 기분이 좋아서 밝은 음악을 듣고 싶다 |
| `sad` | 슬픔, 가라앉음 | 기분이 가라앉아서 위로받고 싶다 |
| `angry` | 화남, 짜증, 답답함 | 오늘 너무 화나고 답답하다 |
| `anxious` | 불안함, 긴장됨 | 조금 불안해서 마음을 가라앉히고 싶다 |
| `tired` | 지침, 피로함 | 지쳤지만 완전히 쉬고 싶지는 않다 |
| `stressed` | 압박감, 스트레스 | 머리가 복잡하고 스트레스가 심하다 |
| `calm` | 차분함, 안정됨 | 마음은 차분한 편이다 |
| `focused` | 집중이 필요함 | 집중해야 해서 방해되지 않는 음악이 필요하다 |
| `lonely` | 외로움, 혼자 있음 | 혼자 있는 밤이라 조용한 음악이 좋다 |
| `hopeful` | 기대감, 긍정적인 긴장 | 새로운 시작을 앞두고 기대된다 |

## 3. 분위기 태그 기준

`mood_tags`는 추천할 음악의 분위기나 질감을 나타낸다.

분위기 태그는 사용자가 듣고 싶은 음악의 방향에 맞춰 붙인다.

| 태그 | 의미 | 추천 방향 |
| --- | --- | --- |
| `soft` | 부드러운 | 강하지 않고 편안한 음악 |
| `quiet` | 조용한 | 집중이나 밤 시간에 어울리는 음악 |
| `light` | 가벼운 | 너무 무겁지 않은 음악 |
| `warm` | 따뜻한 | 위로감이 있는 음악 |
| `uplifting` | 기분을 올려주는 | 활력이나 전환감이 있는 음악 |
| `heavy` | 강한, 무게감 있는 | 분노나 답답함을 풀 수 있는 음악 |
| `minimal` | 단순하고 방해가 적은 | 공부나 작업에 어울리는 음악 |
| `dreamy` | 몽환적인 | 밤, 혼자 있는 상황에 어울리는 음악 |
| `late night` | 늦은 밤 분위기 | 조용한 밤 감성 음악 |
| `acoustic` | 어쿠스틱한 | 자연스럽고 따뜻한 악기 중심 음악 |

## 4. 복합 감정 라벨링

한 문장에 감정이 여러 개 있으면 `emotions`에 여러 태그를 붙인다.

```json
{"text":"불안하지만 너무 어두운 음악은 듣고 싶지 않다","emotions":["anxious"],"mood_tags":["soft","light"]}
```

```json
{"text":"지치고 답답해서 강한 음악으로 기분을 풀고 싶다","emotions":["tired","stressed"],"mood_tags":["heavy","uplifting"]}
```

라벨을 붙일 때는 아래 순서를 따른다.

1. 사용자가 실제로 느끼는 감정을 먼저 찾는다.
2. 사용자가 피하고 싶은 음악 분위기를 확인한다.
3. 사용자가 원하는 음악 분위기를 `mood_tags`로 붙인다.

## 5. 피해야 할 방식

감정 단어 하나만 보고 기계적으로 태그를 붙이지 않는다.

나쁜 예:

```json
{"text":"불안하지만 너무 어두운 음악은 듣고 싶지 않다","emotions":["anxious","sad"],"mood_tags":["heavy"]}
```

이 문장은 `sad`나 `heavy`를 원하는 것이 아니라, 불안하지만 가볍고 부드러운 음악을 원하는 문장이다.

좋은 예:

```json
{"text":"불안하지만 너무 어두운 음악은 듣고 싶지 않다","emotions":["anxious"],"mood_tags":["soft","light"]}
```

## 6. 데이터 작성 원칙

- 한 문장은 실제 사용자가 입력할 법한 자연스러운 문장으로 작성한다.
- 감정 태그는 1개에서 3개 정도만 붙인다.
- 분위기 태그는 1개에서 3개 정도만 붙인다.
- 같은 의미의 문장만 반복하지 않는다.
- 너무 긴 설명문보다 짧고 실제적인 문장을 우선한다.
- 음악 장르보다 감정과 분위기를 우선한다.

## 7. 다음에 확장할 수 있는 태그

현재는 프로젝트 초안이므로 태그 수를 너무 많이 늘리지 않는다.

데이터가 충분히 쌓인 뒤 필요하면 아래 태그를 검토한다.

- `nostalgic`: 그리운, 회상적인
- `romantic`: 로맨틱한
- `energetic`: 에너지 있는
- `relaxed`: 편안한
- `dark`: 어두운

새 태그는 최소 20개 이상의 학습 예시를 만들 수 있을 때 추가한다.
