# 개발 기록

## 2026-05-21 프로젝트 기본 구조 생성

### 작업 목적

문서 초안 정리가 끝난 뒤 실제 구현을 시작하기 위한 기본 폴더 구조를 만들었다.

이번 단계에서는 기능 구현보다 프론트엔드와 백엔드가 들어갈 위치를 먼저 나누는 것을 목표로 했다.

### 작업 내용

- `frontend` 폴더를 생성했다.
- `React + TypeScript + Vite` 기반 프론트엔드 프로젝트를 생성했다.
- 프론트엔드 의존성을 설치했다.
- `backend` 폴더를 생성했다.
- FastAPI 백엔드 기본 구조를 만들었다.
- 백엔드에 `/health` 확인용 API를 추가했다.
- 루트 `.gitignore`를 추가했다.

### 현재 구조

```text
youtube-mood-recommendation
├─ backend
├─ docs
└─ frontend
```

### 확인한 것

- 프론트엔드 빌드가 성공하는 것을 확인했다.
- 백엔드는 Python 실행 환경이 없어 아직 실행하지 못했다.

### 남은 작업

- Python 설치 또는 실행 경로 설정
- FastAPI 서버 실행 확인
- 프론트엔드 기본 화면 정리
- 임시 AI 분석 API 추가
- 프론트엔드와 백엔드 연결
