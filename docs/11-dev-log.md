## 2026-05-22 추천 곡 화면 배치 조정

### 작업 목적

참고 이미지의 `Explore new`와 `Popular` 구조에 맞게 추천 곡 화면 배치를 다시 조정했다.

### 작업 내용

- `Explore new` 역할의 추천 곡 영역에 여러 곡을 앨범 카드 형태로 배치했다.
- 추천 곡 카드를 클릭하면 선택한 곡이 대표곡으로 바뀌도록 했다.
- `Popular` 역할의 상세 영역에 선택한 대표곡 이미지, 제목, 채널명, 추천 이유, YouTube 링크를 표시했다.
- 하단 플레이어 바도 선택한 대표곡을 기준으로 표시되도록 했다.
