# 개발 기록

## 2026-05-21 프로젝트 기본 구조 생성

### 작업 목적

문서 초안 정리가 끝난 뒤 실제 구현을 시작하기 위한 기본 폴더 구조를 만들었다.

이번 단계에서는 기능 구현보다 프론트엔드와 백엔드가 들어갈 위치를 먼저 나누는 것을 목표로 했다.

### 작업 내용

- `frontend` 폴더를 생성했다.
- `React + TypeScript + Vite` 기반 프론트엔드 프로젝트를 생성했다.
- 프론트엔드 의존성을 설치했다.
- `backend` 폴더를 생성했다.
- FastAPI 백엔드 기본 구조를 만들었다.
- 백엔드에 `/health` 확인용 API를 추가했다.
- 루트 `.gitignore`를 추가했다.

### 현재 구조

```text
youtube-mood-recommendation
├─ backend
├─ docs
└─ frontend
```

- 프론트엔드 기본 화면 정리
- 임시 AI 분석 API 추가

## 2026-05-21 프론트엔드 기본 화면 정리

### 작업 목적

Vite 기본 화면을 제거하고 문서에서 정한 한 페이지 구조에 맞는 초기 화면을 만들었다.

### 작업 내용

- 소개 영역을 추가했다.
- 감정이나 상황을 입력하는 입력 영역을 추가했다.
- 추천 결과가 표시될 결과 영역을 추가했다.
- 입력값을 제출하면 임시 태그 예시가 보이도록 했다.
- 모바일 화면에서 입력 버튼과 결과 영역이 세로로 보이도록 스타일을 정리했다.

### 확인한 것

- `npm run lint`가 통과했다.
- `npm run build`가 통과했다.

### 남은 작업

- 백엔드 임시 분석 API 추가
- 프론트엔드에서 실제 API 호출 연결
- 추천 결과 카드 구조 설계

## 2026-05-21 추천 결과 화면 분리

### 작업 목적

추천 음악과 플레이리스트를 더 넓게 보여주기 위해 입력 화면과 추천 결과 화면을 분리했다.

### 작업 내용

- 입력 후 추천 결과 화면으로 전환되도록 화면 상태를 나눴다.
- 추천 결과 화면에 입력 문장과 분위기 태그 예시를 표시했다.
- 다시 입력하기 버튼으로 메인 화면에 돌아갈 수 있게 했다.
- 사용자 흐름, 화면 초안, 메뉴 트리 문서를 결과 화면 분리 구조에 맞게 수정했다.

### 확인할 것

- 입력 후 결과 화면으로 전환되는지 확인한다.
- 다시 입력하기 버튼으로 입력 화면에 돌아오는지 확인한다.

## 2026-05-21 백엔드 임시 분석 API 추가

### 작업 목적

프론트엔드가 사용자 입력 문장을 백엔드로 보낼 수 있도록 임시 분석 API를 만들었다.

이 단계에서는 실제 AI 분석을 하지 않고, 나중에 AI 모델로 교체할 수 있는 응답 구조를 먼저 정했다.

### 작업 내용

- `POST /api/analyze` API를 추가했다.
- 요청 데이터로 사용자 입력 문장을 받도록 했다.
- 응답 데이터에 원본 문장, 감정, 분위기 태그, 검색 키워드를 포함했다.
- 실제 AI 연결 전까지 사용할 임시 분석 함수를 만들었다.
- 백엔드 README에 현재 API 설명과 요청/응답 예시를 추가했다.

### 확인한 것

- `POST /api/analyze` 요청이 정상 응답하는 것을 확인했다.

### 남은 작업

- 프론트엔드에서 백엔드 분석 API 호출 연결
- 결과 화면에서 백엔드 응답 데이터 표시
