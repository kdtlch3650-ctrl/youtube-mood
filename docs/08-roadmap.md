# 로드맵 초안

## 1. 이 문서의 목적

이 문서는 이 프로젝트를 어떤 순서로 만들지 적은 초안이다.

## 2. 진행 순서

1. 기획 초안을 정리한다.
2. 화면 구조를 간단히 정한다.
3. AI가 어떤 값을 내야 하는지 정한다.
4. AI와 YouTube를 연결하는 방법을 정한다.
5. 화면에 결과를 보여주는 구조를 만든다.
6. 필요한 부분을 조금씩 다듬는다.

## 3. 우선순위

- 먼저 문서로 방향을 정한다.
- 그다음 AI와 추천 흐름을 정한다.
- 마지막에 화면을 실제로 연결한다.

## 4. 중요한 점

- 한 번에 너무 많은 기능을 넣지 않는다.
- 작은 단위로 확인하면서 진행한다.
- 문서와 구현 방향이 서로 어긋나지 않게 한다.
