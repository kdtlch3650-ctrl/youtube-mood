# 플로우차트 초안

## 1. 문서 목적

이 문서는 사용자가 입력한 문장이 추천 결과로 이어지는 흐름을 간단히 정리한 초안이다.

## 2. 전체 흐름

```text
사용자 입력
  ↓
문장 분석
  ↓
AI 감정 추론
  ↓
태그 생성
  ↓
YouTube 검색어 생성
  ↓
YouTube 검색
  ↓
추천 결과 표시
```

## 3. 흐름 설명

- 사용자가 감정이나 상황을 입력한다.
- 시스템이 입력 문장을 분석한다.
- AI가 감정과 분위기 태그를 만든다.
- 태그를 검색어로 바꾼다.
- YouTube에서 음악 영상과 플레이리스트를 찾는다.
- 결과를 화면에 보여준다.

## 4. 핵심 기준

- 흐름은 한 방향으로 단순해야 한다.
- 입력부터 결과까지 중간 단계가 보이도록 한다.
- 어디서 AI가 개입하는지 분명해야 한다.
