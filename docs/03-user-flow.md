# 사용자 흐름 초안

## 1. 이 문서의 목적

이 문서는 사용자가 이 서비스를 어떤 순서로 사용하는지 정리한 초안이다.

## 2. 기본 흐름

1. 사용자가 메인 화면에 들어온다.
2. 감정이나 상황을 자연어로 입력한다.
3. 분석 버튼을 누른다.
4. 추천 결과 화면으로 이동한다.
5. 감정과 분위기 태그를 확인한다.
6. 추천된 음악 영상과 플레이리스트를 확인한다.
7. 다른 결과가 필요하면 다시 입력한다.

## 3. 화면 상태

메인 화면
→ 추천 결과 화면
→ 다시 입력

## 4. 사용자가 보게 될 것

- 입력창
- 분석 버튼
- 감정 결과
- 분위기 태그
- 음악 영상 목록
- 플레이리스트 목록

## 5. 흐름의 핵심

- 입력은 짧고 자연스러워야 한다.
- 분석 결과는 사용자가 이해하기 쉽게 보여준다.
- 추천 결과는 영상과 플레이리스트로 나눠서 보여준다.
- 사용자는 결과를 보고 바로 다시 시도할 수 있어야 한다.
