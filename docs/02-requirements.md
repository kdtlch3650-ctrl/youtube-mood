# 핵심 기능 초안

## 1. 이 문서의 목적

이 문서는 이 프로젝트에서 꼭 필요한 기능만 먼저 적어두는 초안이다.

아직 세부 구현은 정하지 않고, 어떤 기능이 필요한지만 정리한다.

## 2. 핵심 기능

- 사용자가 자연어로 감정이나 상황을 입력할 수 있다.
- AI가 입력 문장을 보고 복합 감정과 분위기를 추론할 수 있다.
- 추론 결과를 바탕으로 검색어를 만들 수 있다.
- YouTube에서 음악 영상과 플레이리스트를 검색할 수 있다.
- 검색한 결과를 화면에 보여줄 수 있다.

## 3. 화면에서 보일 것

- 입력창
- 분석 버튼
- AI가 해석한 감정 결과
- 분위기 태그
- 추천 음악 영상
- 추천 플레이리스트

## 4. 이번 초안에서 제외할 것

- 회원가입과 로그인
- 저장 기능
- 좋아요와 댓글
- 개인 맞춤 추천 저장
- 복잡한 설정 화면
