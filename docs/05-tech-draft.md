# 기술 방향 초안

## 1. 이 문서의 목적

이 문서는 이 프로젝트를 어떤 방식으로 만들지 간단히 정리한 초안이다.

아직 사용할 기술을 모두 확정하지 않고, 전체 방향만 적는다.

## 2. 기본 방향

- 화면은 하나의 페이지로 구성한다.
- 입력과 결과를 같은 화면 안에서 보여준다.
- AI는 사용자의 문장을 해석하는 역할을 맡는다.
- YouTube 검색은 AI가 만든 태그를 바탕으로 수행한다.
- 결과는 음악 영상과 플레이리스트를 함께 보여준다.

## 3. 구성 역할

- 프론트엔드는 사용자가 문장을 입력하고 결과를 보는 역할을 한다.
- AI는 문장을 감정과 분위기 태그로 바꾸는 역할을 한다.
- 서버는 AI 결과를 검색 조건으로 바꾸고 YouTube 요청을 처리한다.
- YouTube API는 음악 영상과 플레이리스트를 찾는 역할을 한다.

## 4. 처음에 고려할 것

- 너무 복잡한 구조는 피한다.
- 기능이 잘 보이는 단순한 구조를 우선한다.
- 모바일에서도 보기 편하게 만든다.
- 사용자가 추천 이유를 대략 이해할 수 있도록 태그를 화면에 보여준다.

## 5. 아직 정하지 않을 것

- 어떤 프론트엔드 프레임워크를 쓸지
- 어떤 서버 프레임워크를 쓸지
- AI를 학습형으로 먼저 시작할지
- 태그를 몇 개까지 사용할지
