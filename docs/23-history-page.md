# 기록 페이지 초안

이 문서는 검색 기록을 보여주는 화면의 역할을 정리한다.

## 목적

- 저장한 검색 기록을 실제로 볼 수 있게 하기
- OpenSearch를 붙이기 전에 데이터 활용처를 만들기
- 이전 검색 결과를 다시 확인하기

## 화면 역할

- 최근 검색 목록 보기
- 선택한 기록의 상세 내용 보기
- 입력 문장, 감정, 키워드, 추천 결과 확인

## 데이터 출처

- `GET /api/search-records`

현재는 메모리 저장 데이터를 읽고 있다.

## 화면 구성

### 왼쪽

- 최근 기록 목록
- 각 기록의 입력 문장
- 감정 요약

### 오른쪽

- 선택한 기록의 상세
- 입력 문장
- 검색 시각
- 감정과 키워드
- 추천 곡
- 추천 플레이리스트
