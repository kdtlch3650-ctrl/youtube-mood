# API 초안

## 1. 이 문서의 목적

이 문서는 AI 결과와 YouTube 검색을 어떻게 연결할지 정리한 초안이다.

## 2. API가 할 일

- 사용자의 입력을 받는다.
- 입력을 AI로 전달한다.
- AI 결과를 바탕으로 검색어를 만든다.
- YouTube에서 음악 영상과 플레이리스트를 찾는다.
- 화면에서 사용할 수 있는 형태로 결과를 전달한다.

## 3. 예상 흐름

1. 사용자가 문장을 입력한다.
2. 서버가 그 문장을 AI로 보낸다.
3. AI가 감정과 태그를 돌려준다.
4. 서버가 태그를 검색어로 바꾼다.
5. YouTube 검색을 요청한다.
6. 추천 결과를 화면에서 사용할 수 있는 형태로 전달한다.

## 4. API에서 다룰 데이터

- 사용자 입력값
  - 자연어 문장
- AI 결과
  - 주 감정
  - 보조 감정
  - 분위기 태그
  - 상황 태그
- 검색용 값
  - AI 결과를 바탕으로 만든 검색어
- YouTube 결과
  - 음악 영상 목록
  - 플레이리스트 목록
  - 제목
  - 썸네일
  - 링크

## 5. 중요한 점

- AI와 YouTube 검색 사이의 연결이 명확해야 한다.
- 결과는 화면에서 바로 쓸 수 있어야 한다.
- 나중에 구조가 바뀌어도 수정하기 쉬워야 한다.
