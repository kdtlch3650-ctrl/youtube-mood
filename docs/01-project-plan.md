# 프로젝트 기획 초안

## 1. 프로젝트 이름

감정 기반 음악 추천 웹사이트

## 2. 한 줄 설명

사용자가 자연어로 현재 감정이나 상황을 입력하면, AI가 복합 감정과 분위기를 해석하고 YouTube에서 어울리는 음악과 플레이리스트를 찾아주는 웹사이트를 만들고자 한다.

## 3. 왜 이 프로젝트를 하려는가

사람의 감정은 `기쁨`, `슬픔`처럼 한 단어로만 정리되지 않는 경우가 많다.

예를 들어,

- 지쳤지만 완전히 쉬고 싶은 것은 아니다
- 불안하지만 너무 무거운 음악은 듣고 싶지 않다
- 집중이 필요하지만 차분한 분위기도 필요하다

이 프로젝트는 사용자가 입력한 감정이나 상황에 맞는 음악을 더 쉽게 찾을 수 있게 하는 것을 목표로 한다.

## 4. 이 프로젝트에서 확인하고 싶은 것

- 자연어 문장을 감정과 분위기로 바꿀 수 있는가
- AI 결과를 검색 키워드로 연결할 수 있는가
- YouTube 검색 결과를 음악 추천처럼 보이게 구성할 수 있는가

## 5. 예상 사용자

- 기분에 맞는 음악을 빠르게 찾고 싶은 사용자
- 단순 키워드 검색보다 분위기 기반 추천을 원하는 사용자

## 6. 현재 생각하는 기본 방향

1. 사용자가 자연어 문장을 입력한다.
2. AI가 복합 감정과 분위기 태그를 추론한다.
3. 추론 결과를 검색 가능한 키워드로 바꾼다.
4. YouTube API로 음악 영상과 플레이리스트를 검색한다.
5. 추천 결과를 화면에 보여준다.

## 7. 이번 버전에서 우선 고려할 범위

- 자연어 입력
- 복합 감정 추론
- 분위기 태그 생성
- YouTube 기반 추천
- 영상과 플레이리스트 함께 보여주기

## 8. 이번 단계에서 아직 확정하지 않을 것

- AI를 학습형으로 할지 규칙형으로 할지
- 감정 라벨을 몇 개로 둘지
- 화면 구성을 얼마나 자세히 잡을지
- 저장 기능이나 로그인 기능이 필요한지
