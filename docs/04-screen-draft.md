# 화면 초안

## 1. 이 문서의 목적

이 문서는 이 서비스에서 필요한 화면과 각 화면의 역할을 간단히 정리한 초안이다.

## 2. 화면 구성

- 메인 화면
- 추천 결과 화면

## 3. 각 화면의 역할

### 메인 화면

- 서비스 이름을 보여준다.
- 어떤 서비스인지 짧게 설명한다.
- 감정이나 상황을 입력하는 영역을 둔다.
- 분석 버튼을 둔다.

### 추천 결과 화면

- AI가 해석한 감정과 분위기를 보여준다.
- 추천된 음악 영상과 플레이리스트를 보여준다.
- 다시 입력할 수 있는 버튼을 둔다.

## 4. 화면에서 중요한 점

- 입력 화면은 단순하게 유지한다.
- 추천 결과 화면은 음악과 플레이리스트를 충분히 보여줄 수 있어야 한다.
- 사용자는 결과를 본 뒤 다시 입력 화면으로 돌아갈 수 있어야 한다.

## 5. 모바일 고려

- 모바일에서도 입력 화면과 추천 결과 화면을 편하게 볼 수 있어야 한다.
- 입력창과 버튼은 세로로 길게 배치한다.
- 추천 결과는 카드 형태로 한 줄씩 쌓아 보여준다.
- 작은 화면에서는 요소 간 간격을 넉넉하게 둔다.
