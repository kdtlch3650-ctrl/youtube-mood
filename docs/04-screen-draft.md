# 화면 초안

## 1. 이 문서의 목적

이 문서는 한 페이지 안에서 어떤 영역이 필요한지 간단히 정리한 초안이다.

## 2. 화면 구성

- 소개 영역
- 입력 영역
- 결과 영역

## 3. 각 영역의 역할

### 소개 영역

- 서비스 이름을 보여준다.
- 어떤 서비스인지 짧게 설명한다.

### 입력 영역

- 감정이나 상황을 입력하는 영역을 둔다.
- 분석 버튼을 둔다.

### 결과 영역

- AI가 해석한 감정과 분위기를 보여준다.
- 추천된 음악 영상과 플레이리스트를 보여준다.
- 다시 입력할 수 있는 버튼을 둔다.

## 4. 화면에서 중요한 점

- 한 페이지 안에서 흐름이 이어지도록 구성한다.
- 사용자가 바로 입력하고 바로 결과를 볼 수 있어야 한다.
- 같은 화면 안에서 입력과 결과가 자연스럽게 이어져야 한다.

## 5. 모바일 고려

- 모바일에서도 한 화면 안에 입력과 결과가 보이도록 만든다.
- 입력창과 버튼은 세로로 길게 배치한다.
- 추천 결과는 카드 형태로 한 줄씩 쌓아 보여준다.
- 작은 화면에서는 요소 간 간격을 넉넉하게 둔다.
