# 최종 점검 체크리스트

## 1. 문서 목적

이 문서는 프로젝트를 마무리하기 전에 기능, 실행 환경, 문서, Git 상태를 확인하기 위한 체크리스트이다.

## 2. 실행 환경 확인

- [ ] 백엔드 서버가 실행되는가

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

- [ ] 백엔드 상태 확인 API가 정상 응답하는가

```text
http://127.0.0.1:8000/health
```

- [ ] 프론트엔드 개발 서버가 실행되는가

```powershell
cd frontend
npm run dev -- --host 127.0.0.1 --port 5173
```

- [ ] 프론트 화면이 브라우저에서 열리는가

```text
http://127.0.0.1:5173
```

## 3. 핵심 기능 확인

- [ ] 자연어 문장을 입력하면 결과 화면으로 이동하는가
- [ ] 추천 곡 목록이 표시되는가
- [ ] 플레이리스트 목록이 표시되는가
- [ ] 추천 곡 카드를 선택하면 대표 영역과 하단 플레이어가 바뀌는가
- [ ] 플레이리스트를 선택하면 내부 곡 목록이 표시되는가
- [ ] 플레이리스트 내부 곡을 선택하면 하단 플레이어와 대표 이미지가 바뀌는가
- [ ] 이전 곡 / 재생 / 다음 곡 버튼이 동작하는가
- [ ] 하단 재생 바를 드래그해 재생 위치를 조정할 수 있는가
- [ ] 긴 제목이 화면을 깨뜨리지 않는가

## 4. 추천 로직 확인

- [ ] 장르가 들어간 문장에서 장르가 추출되는가

예:

```text
오늘은 특히 너무 지쳐 신나는 댄스음악 추천해줘
```

- [ ] 장르가 없는 문장에서 잘못된 장르가 추출되지 않는가

예:

```text
집에서 쉬고 싶은데 편안한 음악 추천해줘
```

- [ ] 회피 표현이 분위기 태그에 반영되는가

예:

```text
불안하지만 너무 무거운 음악은 싫어
```

- [ ] `전체` 검색 옵션이 기존 검색 흐름을 유지하는가
- [ ] `한국어 중심` 검색 옵션이 한국어 검색어를 생성하는가

## 5. 테스트 스크립트 확인

- [ ] 정식 단위 테스트가 통과하는가

```powershell
cd backend
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

- [ ] 추천 케이스 확인 스크립트가 통과하는가

```powershell
cd backend
.\.venv\Scripts\python.exe scripts\check_recommendation_cases.py
```

기대 결과:

```text
TOTAL: 16
PASS: 16
CHECK: 0
```

- [ ] 프론트 빌드가 통과하는가

```powershell
cd frontend
npm run build
```

- [ ] 모델 파일이 Git에 포함되지 않는가
- [ ] 모델 산출물 관리 문서가 최신 상태인가

## 8. Git 상태 확인

- [ ] 작업 트리가 깨끗한가

```powershell
git status --short
```

- [ ] `.env` 파일이 Git에 포함되지 않았는가
- [ ] `ml/models/`의 모델 파일이 Git에 포함되지 않았는가
- [ ] 원본 학습 데이터와 변환된 대용량 학습 데이터가 Git에 포함되지 않았는가
- [ ] 커밋 메시지가 작업 단위로 구분되어 있는가

## 9. 현재 한계 확인

- [ ] YouTube 검색 결과는 외부 API 상태에 따라 달라질 수 있음을 문서에 적었는가
- [ ] 한국어 중심 옵션이 한국 곡만 보장하지 않는다는 점을 문서에 적었는가
- [ ] fallback 모델은 학습 모델보다 표현 이해 범위가 좁다는 점을 문서에 적었는가
- [ ] 모델 파일은 별도 관리 대상이라는 점을 문서에 적었는가
