# AI 초안

## 1. 이 문서의 목적

이 문서는 이 프로젝트에서 AI가 어떤 일을 하는지 정리한 초안이다.

## 2. AI의 역할

- 사용자가 입력한 문장을 읽는다.
- 문장에서 감정과 분위기를 찾는다.
- 복합 감정을 간단한 태그로 바꾼다.
- YouTube 검색에 쓸 수 있는 단어를 만든다.

## 3. AI가 다뤄야 할 것

- 주 감정
- 보조 감정
- 분위기 태그
- 상황 태그
- 검색어 힌트

## 4. AI가 하지 않을 것

- 음악을 직접 재생하지 않는다.
- 추천 결과를 스스로 완성하지 않는다.
- 사용자 취향을 장기적으로 저장하지 않는다.

## 5. 생각 중인 출력 형태

AI는 문장을 바로 보여주는 대신, 화면에서 쓸 수 있는 짧은 정보로 바꾸는 방식이 적절하다.

예시:

- `mainEmotion`
- `secondaryEmotions`
- `moodTags`
- `searchKeywords`

## 6. 중요한 점

- AI 결과는 너무 복잡하지 않아야 한다.
- 검색에 바로 쓸 수 있어야 한다.
- 화면에서 사용자가 이해할 수 있어야 한다.
