# 검색/추천 테스트 케이스

## 1. 문서 목적

이 문서는 자연어 입력이 감정 분석, 장르 추출, 검색 옵션, YouTube 추천 결과로 이어지는 흐름을 확인하기 위한 기준을 정리한다.

자동 테스트 코드가 아니라, 추천 결과가 의도한 방향에 가까운지 사람이 확인하기 위한 체크리스트이다.

## 2. 확인 기준

각 테스트 문장은 아래 기준으로 확인한다.

- 감정 라벨이 문장 의도와 크게 어긋나지 않는가
- 장르를 직접 입력한 경우 장르가 올바르게 추출되는가
- 회피 표현이 분위기 태그에 반영되는가
- 검색 옵션이 추천 결과 방향에 영향을 주는가
- 추천 곡과 플레이리스트가 입력 문장과 설명 가능한 관계를 가지는가

## 3. 테스트 케이스

### 3.1 지친 상태에서 신나는 댄스 음악을 원하는 경우

입력 문장:

```text
오늘은 특히 너무 지쳐 신나는 댄스음악 추천해줘
```

검색 옵션:

```text
한국어 중심
```

기대 결과:

- 장르: `dance`
- 분위기: `uplifting`, `light`, `warm` 중 일부
- 검색 방향: 신나는 댄스 음악, 기분전환 음악
- 확인할 점: 해외 댄스 음악만 나오기보다 한국어 검색 결과도 섞이는지 확인한다.

### 3.2 불안하지만 무거운 음악은 피하고 싶은 경우

입력 문장:

```text
불안하지만 너무 무거운 음악은 싫어
```

검색 옵션:

```text
전체
```

기대 결과:

- 감정: `anxiety` 계열
- 분위기: `soft`, `light`, `quiet` 중 일부
- 피해야 할 방향: `heavy`, `late night` 중심 검색
- 확인할 점: 불안 감정이 있어도 너무 어둡거나 강한 음악으로 치우치지 않는지 확인한다.

### 3.3 재즈 장르를 직접 말한 경우

입력 문장:

```text
오늘은 지쳤는데 차분한 재즈 음악 듣고 싶어
```

검색 옵션:

```text
전체
```

기대 결과:

- 장르: `jazz`
- 분위기: `soft`, `quiet`, `warm` 중 일부
- 검색 방향: 차분한 재즈 음악
- 확인할 점: 검색어와 추천 결과에 재즈 장르가 반영되는지 확인한다.

### 3.4 한국어 중심 재즈 추천을 원하는 경우

입력 문장:

```text
오늘은 지쳤는데 차분한 재즈 음악 듣고 싶어
```

검색 옵션:

```text
한국어 중심
```

기대 결과:

- 장르: `jazz`
- 검색 방향: 차분한 재즈 음악, 따뜻한 재즈 음악
- 확인할 점: `전체` 옵션보다 한국어 제목이나 한국어 플레이리스트가 더 잘 섞이는지 비교한다.

### 3.5 일반 단어를 장르로 잘못 인식하지 않아야 하는 경우

입력 문장:

```text
집에서 쉬고 싶은데 편안한 음악 추천해줘
```

검색 옵션:

```text
전체
```

기대 결과:

- 장르: 없음
- 분위기: `soft`, `warm`, `quiet` 중 일부
- 확인할 점: `house` 같은 장르로 잘못 인식되지 않아야 한다.

### 3.6 음악 문맥이 있는 애매한 장르

입력 문장:

```text
하우스 음악으로 신나는 곡 추천해줘
```

검색 옵션:

```text
전체
```

기대 결과:

- 장르: `house`
- 분위기: `uplifting`, `light` 중 일부
- 확인할 점: 음악 문맥이 있으므로 하우스 장르로 인식되는지 확인한다.

### 3.7 집중이 필요한 경우

입력 문장:

```text
공부해야 해서 집중이 잘 되는 음악이 필요해
```

검색 옵션:

```text
전체
```

기대 결과:

- 감정 또는 상태: `focus` 계열
- 분위기: `minimal`, `quiet` 중 일부
- 검색 방향: 집중 음악, 미니멀한 음악
- 확인할 점: 너무 신나는 음악보다 집중에 방해되지 않는 결과가 나오는지 확인한다.

### 3.8 슬프지만 더 우울해지고 싶지는 않은 경우

입력 문장:

```text
조금 슬프지만 더 우울해지는 노래는 듣고 싶지 않아
```

검색 옵션:

```text
전체
```

기대 결과:

- 감정: `sadness` 계열
- 분위기: `warm`, `light`, `soft` 중 일부
- 피해야 할 방향: 지나치게 어두운 플레이리스트
- 확인할 점: 슬픈 감정은 반영하되 너무 우울한 방향으로 검색되지 않는지 확인한다.

## 4. 결과 기록 방식

테스트할 때는 아래 형식으로 간단히 기록한다.

```text
입력:
검색 옵션:
실제 장르:
실제 mood_tags:
실제 추천 결과:
판단:
수정 필요 여부:
```

## 5. 현재 한계

- YouTube 검색 결과는 API와 외부 데이터에 따라 계속 달라질 수 있다.
- 같은 검색어라도 시점에 따라 추천 결과가 달라질 수 있다.
- 이 문서는 정확도 평가표가 아니라 추천 방향을 확인하기 위한 기준이다.

## 6. 실행용 테스트 세트

아래 테스트 세트는 코드로 반복 확인하기 위한 기준이다.

`기대 검색어 방향`은 실제 YouTube 결과 제목을 고정하는 기준이 아니다.
백엔드가 어떤 검색어를 만들어야 하는지 확인하기 위한 기준이다.

| 번호 | 입력 문장 | 검색 옵션 | 기대 장르 | 기대 검색어 방향 |
| --- | --- | --- | --- | --- |
| T01 | 오늘은 특히 너무 지쳐 신나는 댄스음악 추천해줘 | 한국어 중심 | `dance` | 댄스 음악 |
| T02 | 불안하지만 너무 무거운 음악은 싫어 | 전체 | 없음 | soft, light, quiet 계열 |
| T03 | 오늘은 지쳤는데 차분한 재즈 음악 듣고 싶어 | 전체 | `jazz` | jazz music |
| T04 | 오늘은 지쳤는데 차분한 재즈 음악 듣고 싶어 | 한국어 중심 | `jazz` | 재즈 음악 |
| T05 | 집에서 쉬고 싶은데 편안한 음악 추천해줘 | 전체 | 없음 | 편안한 분위기 |
| T06 | 하우스 음악으로 신나는 곡 추천해줘 | 전체 | `house` | house music |
| T07 | 공부해야 해서 집중이 잘 되는 음악이 필요해 | 전체 | 없음 | minimal, focus, quiet 계열 |
| T08 | 조금 슬프지만 더 우울해지는 노래는 듣고 싶지 않아 | 전체 | 없음 | warm, light, soft 계열 |
| T09 | 화가 나서 답답한데 너무 시끄러운 건 말고 락 음악 듣고 싶어 | 전체 | `rock` | rock music |
| T10 | 기분이 좋아서 케이팝 플레이리스트 듣고 싶어 | 한국어 중심 | `kpop` | 케이팝 플레이리스트 |
| T11 | 밤에 혼자 걷는데 로파이 음악이 듣고 싶어 | 전체 | `lofi` | lofi music |
| T12 | 머리가 복잡해서 잔잔한 클래식 음악 추천해줘 | 한국어 중심 | `classical` | 클래식 음악 |
| T13 | 우울하지만 너무 슬픈 노래는 피하고 싶어 | 전체 | 없음 | warm, light 계열 |
| T14 | 요즘 자꾸 함정에 빠지는 것 같아서 답답한데 음악 추천해줘 | 전체 | 없음 | 장르 미인식 |
| T15 | 트랩 음악으로 강한 비트 추천해줘 | 전체 | `trap` | trap music |
| T16 | 오늘은 신나는 팝 음악 듣고 싶어 | 한국어 중심 | `pop` | 팝 음악 |

## 7. 테스트 실행 결과 기록

실제 테스트를 돌린 뒤 아래 형식으로 결과를 추가한다.

```text
실행일:
테스트 방식:
통과:
주의:
실패:
메모:
```

### 2026-05-28 실행 결과

테스트 방식:

```text
문서의 실행용 테스트 세트 16개를 읽어 백엔드 분석 로직으로 실행
```

확인 항목:

- 장르 추출 결과
- `mood_tags`
- `전체` 또는 `한국어 중심` 검색어 생성 결과

결과:

```text
총 테스트: 16개
통과: 16개
확인 필요: 0개
```

확인된 문제와 처리:

```text
T14: 요즘 자꾸 함정에 빠지는 것 같아서 답답한데 음악 추천해줘
```

이 케이스는 사용자가 실제로 음악 장르를 말한 것이 아니라 감정 상황을 설명한 문장이다.

따라서 `trap` 같은 장르로 연결하지 않고, 장르 없이 감정과 분위기 중심으로 추천해야 한다.

수정 후 결과:

```text
T14 actual_genre: None
T14 query: soft emotional music
```

대표 확인 결과:

```text
T01 query: 따뜻한 댄스 음악
T04 query: 따뜻한 재즈 음악
T10 query: 따뜻한 케이팝 음악
T12 query: 따뜻한 클래식 음악
T16 query: 따뜻한 팝 음악
```
