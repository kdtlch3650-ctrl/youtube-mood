# 사용자 요구사항 초안

## 1. 이 문서의 목적

이 문서는 사용자가 이 서비스에서 원하는 것과 필요한 것을 정리한 초안이다.

## 2. 사용자가 원하는 것

- 현재 감정에 맞는 음악을 쉽게 찾고 싶다.
- 복잡한 검색어를 직접 만들고 싶지 않다.
- 기분에 맞는 음악과 플레이리스트를 같이 보고 싶다.
- 입력한 문장에 맞는 추천 결과를 바로 보고 싶다.

## 3. 사용자가 필요로 하는 것

- 자연어로 감정이나 상황을 입력할 수 있는 입력창
- 입력 내용을 해석해주는 AI 분석
- 결과를 이해하기 쉬운 감정 태그
- 추천 결과를 보여주는 화면
- 다시 입력해서 다른 결과를 볼 수 있는 기능

## 4. 사용자가 불편해할 수 있는 점

- 너무 많은 설정이 있으면 불편하다.
- 결과가 너무 복잡하면 이해하기 어렵다.
- 영상과 플레이리스트가 따로 놀면 추천처럼 느껴지지 않는다.
- 모바일에서 보기 불편하면 사용하기 어렵다.

## 5. 이 문서에서 중요한 점

- 사용자는 복잡한 구조보다 바로 쓸 수 있는 구조를 원한다.
- 사용자는 결과가 왜 나왔는지 대략 이해하고 싶어 한다.
- 사용자는 한 번 입력한 뒤 바로 결과를 보고 싶어 한다.
